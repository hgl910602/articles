# 电商服务商体系的理解

## 一、什么是电商服务商

对于消费者而言，服务商并不像商家这么被消费者强感知，更多是隐藏在商家及平台身后的存在，通过垂直领域的专业能力补充及提升平台及商家的经营能力和效率，与商家以及平台一起支撑起电商这个十万亿市场。

电商服务商是一个相对较泛的概念，与其他类型的服务商没有本质上的区别，都是作为能力补充者的角色存在。当平台无法满足所有需求的时候，或者商家经营链路中有节点搞不定时，需要适当的引入专业的三方来对能力缺位的地方进行补位，从而实现全局的ROI最高。对于服务商而言，通过专业能力补充能力短板并从中收取相关服务收入，是其商业模式可运转的基石。

我们常见的有像提供ERP能力的聚水潭、万里牛，数据相关的考古家、蝉妈妈，流量转化的索象电商，品牌影响力建设的火蝠电商、融趣传媒、派芽星球，全店代运营的宝尊电商、丽人丽妆等等都可以理解为是电商的服务商体系中的一部分。

### 工具类服务商

工具类是指以提供工具为主的服务商，强调技术标准化，其主要服务目标是商家，平台一般情况下不太需要此类服务商，毕竟很少存在多平台共性的所谓接口能够聚合的能力，这类服务商大体通过包装平台提供的接口/数据形成满足特定领域的小工具，比如订单管理工具、比如打单工具、比如抽奖小工具。

这里做的比较出名的是各类ERP系统，比如说旺店通、万里牛、网点管家等等，这些服务商以对商家的需求挖掘以及理解为基础，叠加各大平台的对外接口，组装成更适合于特定领域商家使用的工具，比如像各大ERP系统就可以很好的满足店铺的跨店经营诉求，这里覆盖也就是平台无法满足的能力。

### 服务型服务商

服务型服务商更多的是以服务的形式给客户提供帮助，比如平台觉得新商引入专门建团队ROI太低，那就会有专门的公司来承接此类需求，再比如商家没有客服，那会有专门的公司储备一堆的客服人力，然后池化分包卖给商家，让商家能够掏点钱就满足所谓3分钟回复率的要求。服务型服务商普遍而言提供的服务是非标的，不像工具型服务商那样提供的是批量生产的服务，更强调的是经验以及知识的指导，因此整体上而言相对更吃人力。

服务型服务商再向下逻辑上可以依据所服务领域的不同产生不同的分类，但由于客户会有千奇百怪的需求，服务本身较难标准化定义，因此无法全量对齐分类，但比较常见的会有代运营类（全托管、职能托管，职能托管里又能分为客服托管、投流托管、营销托管、仓储托管等等），代制作类（主要是素材代制作）。

对于平台而言服务商可能就没有那么清晰的分类，主要看平台需要什么就定制化的满足什么，以人力及行业经验输出为主，辅助平台做一些冷起或者ROI没那么高的事情。

服务型服务商在物理世界中大量存在，其数量远多于工具型服务商，就像工业化生产的商品，其竞争程度必然远惨烈于服务型商品，最后能够在市场上存活的只会是分层后的那么几家。而服务本身作为非标的存在，对客户需求的完美满足能够容纳更多的玩家。

下面从多个维度对比一下两类服务商的差异，能够有些明显的体感

|  | 工具型服务商 | 服务型服务商 |
| --- | --- | --- |
| 核心能力 | 专注标准化产品开发（API封装、模块化功能）<br>基础能力构建 | 业务流程整合（全生命周期管理）<br>行业know-how积累（运营经验/资源协调） |
| 产品形态 | 标准化SaaS平台/软件产品<br>功能模块叠加扩展 | 定制化解决方案+人工服务<br>动态调整服务内容 |
| 收费模式 | 订阅制收费<br>按功能模块定价 | 项目制收费+效果分成<br>按服务周期计价 |
| 当前趋势 | 向智能化演进（AI客服系统）<br>生态平台集成 | 向融合化发展（增加工具模块）<br>服务场景延伸 |
| 风险特征 | 同质化竞争压力 | 服务质量波动风险<br>客户续约率不稳定 |

## 三、服务商存在的意义

我们讨论服务商存在价值的时候，需要回归到一个问题上，那就是为什么平台不去满足所有需求而非要让别人在电商这个庞大的市场分一杯羹，这个问题似乎是一个很蠢的问题，但深思下去，就会发现服务商生态是电商平台很难绕过去的一个角色。

### 于平台而言，存在着想不想以及能不能的问题

首先一个很容易想到的原因就是ROI，也就是平台想不想的问题，当平台自身提供能力的收益整体评判下来低于引入外部三方的收益的时候，平台就倾向于不做，而是放任这部分由市场来满足，经济学中的比较优势理论在这里也能够有所体现。比如业务冷起时的供给引入、消费者吸引、货品引入等等，平台构建一个组织满足这个需求可能要付出每年5000w，但找三方只需要1000w，那平台就会倾向于找三方合作。或者再比如说某些个别类目的商家需要一个非常小众的商品管理能力，这个平台去做要投入大量人力各种定制，这种就不如把这块放出去给三方实现。

第二类是有些需求是平台无法满足的，也就是平台能不能的问题，比如商家的跨平台经营的诉求，这个任何一个电商平台都是无法满足的需求，它天然合法且合理，毕竟商家与平台是企业间的合作关系，而不是隶属关系，逼迫商家经营二选一在当前环境下必然会遭到社会主义铁拳的重击，这类脱离平台的需求只能由三方来满足。这类的需求也不少，再比如一些较大的商家自己本身有相关的库管系统、仓储系统等需要打通对接之类的场景。

### 于商家而言，主要是存在着想不想的问题

首先作为实际经营以及利润追求主体的商家，逻辑上而言他应该会经营链路中的所有能力，不应该存在解决不了的问题的问题（如果有那大概率是不合法的事情），毕竟所有不能的问题都可以通过学习来解决。

因此对于商家而言，服务商的能力选择核心取决于ROI的考量，如果自己做一件事情的成本高于给服务商掏的钱，那么商家会倾向于掏钱来解决问题。举例比如说商家客服，平台为了提升消费者体验，用三分钟回复率来考核商家，逻辑上商家就需要配备一个客服来尽快响应消费者，但这就让开店变成了坐班，某些商家不想/没精力坐班但又想满足平台要求，所以需要有三方的人来帮他打理一下这类问题。这类的能力缺失的case很多，比如客服、比如视频制作、比如拍卖家秀等等。

整体来看，服务商体系其实是电商生态中重要的一环，它看起来是一个可选的存在，但实际上各大电商平台都会来使用服务商生态来解决平台/商家能力缺失问题。

## 四、服务商的经营模式

在服务商这套体系里，商家以及平台会变成类消费者的角色，而服务商会变成类商家的角色。但服务商体系与我们熟悉的电商消费者商家体系那一套有非常大的不同，服务商本质上是一个B2B的生意。

我们回顾一下电商的业务模式，对于电商而言，各大平台整体对C端用户的动线进行了抽象分析归类设计然后叠加用户心智教育，之后通过标准化整个导购交易链路来实现了需求的最大公约数的归一化，形成了近似一体化的需求大盘，至少可以说可以抽象出不同的共性盘子，从而将需求固化在平台，然后规模化的匹配B端供给，进行人货撮合，事情就变得很顺畅，也就是做好人货场的概念，平台会通过各种办法搞定商家以及消费者的引入问题，商家主要通过平台提供的各种工具，在平台的各类流量分配算法中做文章，找到消费者并成交。

但服务商本质上做的是B2B的生意，toB的生意普遍有一个特点就是客户少、总价高、定制化要求多、服务响应要求严格，服务这些公司的生意更像是做外包，客户选择性的把一些不能做或者ROI低的部分给剥离出来，通过付费的方式驱动专业公司去做事。同样对于承接公司而言，客群稳定、利润相对有保障普遍是这类生意的特点，只要维持好几个大客户，公司一段时间的经营现金流就是有确定性的。由于B2C以及B2B模式的差异，导致像做toC客户一样去做ToB几乎注定不太可能成功。

前置能力建设阶段是属于服务商本身的内功，修炼内功使得自己能够有更高的竞争力这个是服务商的必修课。

客户获取阶段相当于是各大服务商的客户入水口，分散非标的需求带来了分散非标的供给，行业内很难形成像猫狗拼抖快这样的平台来进行，就会是传统的B端企业获客方式，也就是八仙过海各显神通的自己找客户。因此服务商的获客模式是非常多元的，需要打造自己的品牌影响力，或者说行业口碑，服务商应该说更像一个传统的销售公司，大部分的服务商公司需要维持一个销售团队将自己的产品/服务售卖出去。

推进到售前阶段，就是已经过滤一道后的客户，进一步深化理解客户需求并与自身能力做匹配，然后吸引客户做真正的转化，这一步也比较依赖于服务商的真实本领。售中售后就不多做介绍了，依据合同将服务交付给客户，然后为了长久的合作，同步需要实时进行相关的客户管理。

我们回到电商服务商领域，前面讲到过服务商大体可以分为工具型以及服务型，工具型的服务商（比如卖标准数据、软件）提供的相对而言要好一点，把自己的垂直领域能力做的完善一点，然后再降低业务支持范围只匹配完全match能力的客户，这样就能够尽可能的标准化服务做成所谓的“商品”规模化售卖，但当规模做大后，对于供给的企业而言，服务化就是一个必须要构建的能力，毕竟它市场更大，利润更丰厚，客户迁移成本更高更有利于。像聚水潭这类业内口碑做的很大的erp垂直领域的工具，仍要针对不同的大客户做二次开发。

更贵更大市场的服务型服务商，更多的就需要围绕客户需求为中心去尽可能的case by case的定制化服务及收费。毕竟服务是一个很主观的东西，业务行业第一的服务商，针对不同阶段不同行业的商家可能达到的效果是很难完全一样。

这里简单讲一下服务商的盈利模式，其实感觉也没太多可讲的，一句话总结：为谁服务谁掏钱，这个也是个天经地义的事情。比如给商家提供工具或者帮助商家运营提升经营效率那自然是商家掏钱，为平台招募新商、培育新商，那自然是平台掏钱，但不论哪个模式，都是企业与企业之间的合作，它与我们常见的一手交钱一手交货的零售体系是完全不同的。

## 五、电商平台与服务商的关系

平台与服务商的共生关系本质是专业化分工的必然选择。根据贝恩咨询研究，平台自建服务体系的边际成本是第三方服务的3.2倍。从上面我们也简单梳理过服务商的存在的意义，可以看到在电商领域，不论是于商家还是于平台而言，都有着其不可替代性。

“在2023年9月初，抖音生活服务启动“区域服务商业务”，宣称将在平台已覆盖的100个下沉城市中，通过“一城一策”的运营方式，吸引并联合优质区域服务商，共同服务好本地中小商家需求，激发下沉市场新消费。而根据抖音的数据来看，2023年入驻服务商的数量增长了1.78倍，服务商交易总额也提升了近8倍之多”

因此平台对于服务商普遍是一个支持的态度，为了支持服务商体系，平台普遍会采取两条腿走路分别扶持工具型以及服务型的两类服务商。

这里我们主要讨论服务对象是商家的服务商，因为服务于平台的服务商本身就是属于企业间的合作，平台作为出资的甲方会对服务商提出相关目标达成要求，并配合服务商进行相关的数据分享。

### 工具型服务商

工具型服务商，各大电商平台一般都会有开放平台对外，将内部的部分api接口开放给三方，供三方进行二次开发迭代，以满足平台无法覆盖的商家诉求，比如打单工具、发货工具等，这个是由平台基于商家诉求平台可以满足但无法满足的立场站位做的一个能力。里面会包括开发者的入驻 -> 接口使用 -> 工具组装 -> 工具发布的能力。工具开发好之后，同样会提供相关的展示场域供商家可见以及可订阅。

在这个过程中，平台的原子能力输出，获得的是更垂直更细分场域的效率工具辅助商家经营，从而达到全局效率的最优，在当前成熟的电商平台中，开放的API也会收费，当然这个收费一般而言不会特别贵，一个方面是能够增加营收，另外一个方面也有助于提升恶意服务商利用平台善意能力作恶的成本。

同时纯工具产出后，仅仅是只能完成服务商垂直能力的储备，其他方面的运营手段与服务型服务商并无区别，因此也会按照服务型服务商进行相同的帮扶，只是服务是这个工具的售卖过程。

### 服务型服务商

相比于工具型服务商，服务型的服务商，个人理解平台主要的做功方向存在于以下个阶段：

- 优质服务商的主动引入
- 商家需求发现
- 辅助信任体系的构建
- 辅助商家经营工具构建

为什么只有这几个阶段，我们用下上面的一张关于服务商运营的图，从图上可以看到，在服务商与客户的合作过程中，售前、售中、售后三个阶段的大部分都需要服务商依据自身的专业能力围绕客户需求进行打磨，平台唯一可以介入的点就是与客户能力交叉的部分，其实也就是起到打辅助的作用。

### 优质服务商的主动引入

如何引入以及运营真正优质的服务商，不论是工具型的还是服务型的，这个是非常考验平台的一件事情。对于电商商家而言大部分的平台的做法是大量的准入+治理。在准入侧尽可能的在满足法律法规的基础上做低门槛，大量的放供给进来，做大基数通过概率理论来出成绩，比如10w个里总应该会有1个优质的，然后再通过各种治理规则牵引去干掉那些不优质且没有成长意愿的，从而提升平台整体的供给质量。但服务商场域这个也不好做，因为市场盘子就那么大，门槛又高，全国的总量就是有限的，入水口放大可能也很难招到足够多的服务商主动进来，因此平台需要辅以足够的利益吸引，以及一定的定招手段定向去发掘优质服务商，比如各垂类领域的top型公司。

### 商家需求发现

对于需求，由于平台手握全量商家信息情况，因此这一步是平台需要承担的，本质上解决的是客户触达的问题，也会是吸引各服务商入驻的主要的点。这个依赖于平台引入的商家质量以及规模情况，如果商家盈利情况差，那商家可能不太愿意从原本就微薄的利润中划分部分去找增值性质的服务商服务自己，所以平台对于商家的理解以及分层是需要有的，这也是比较难做的地方。

如经营必备工具的工具型可以匹配新商，垂直领域代运营服务可以匹配给对应垂直能力缺失的盈利商家，中大型服务型服务商可以匹配给有稳定盈利能力的成熟商家。

### 辅助信任体系构建

信任体系的构建是为了解决转化率的问题，也就是背撮合成功率指标，只有有了这套体系，在系统层面搜索及推荐等撮合场域才能有足够的展示在需求端的吸引点，同时在物理层面这套体系会成为平台官方为服务商的背书，提升服务商的可信度从而增大撮合成功概率，在电商生态里我们讲过，消费者能够将对平台/达人的信任转嫁覆盖到商品上，同样在服务商领域，平台的背书一定程度上能够提升商家的信任度，比如某商家是在客服代运营领域平台上的五星级服务商，那商家在选择时自然也可能将一定的平台信任覆盖到这个服务商身上。

这里就需要下苦力气去建设各种指标去辅助识别，比如说投入度识别，比如说效果满意度建设，再比如商家签约时发布一个任务监督这个任务的达成率，再比如商家的主动评价、续费率、增购率等等。

### 撮合场域构建

有了以上的基础，平台有了相关的各类数据以及相关指标，就可以通过构建各式各样的场域对需求的双端进行撮合，一般而言各平台会通过构建服务市场提供商家的主动发现能力，通过在商家经营工作台构建相关推荐能力提供商家的被动发现能力。

### 辅助商家经营工具的构建

这个毋庸置疑，商家在平台、功能在平台、数据在平台，为了能够让服务商更好的辅助商家经营，因此平台会基于提效思考开发相关工具供服务商使用，能够尽可能的帮助服务商提升商家。

总结而言，电商对于各大服务商是持一个欢迎态度，并在引入以及撮合上进行做功，尽可能的帮助服务商成长，同时带动服务商帮助平台上的商家成长。
