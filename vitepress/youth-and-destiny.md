# 少年气与知天命

![一个工作近十年的人走向未知的路，身后的少年影子已经向前跑去](/images/youth-and-destiny/youth-and-destiny.webp)

工作小十年的一点思考，改下手写，大模型的AI感实在是太重了。

前段时间跟人聊起一个问题，说人岁数大了就没有创新精神了，是不是本质上就是缺了年轻时一往无前的勇气。这个问题我其实挺有感触的，目前自己毕业10年，懂的东西比二十多岁的时候多了很多，但真要开个新东西，第一反应已经从怎么做变成了要不要做，收益有多大。

更有意思的是，我自己也清楚事情是做出来的，不是想出来的等出来的，日常也在教育我儿子事情是做完的，不是磨完的，道理都懂，但有的事情手上就是不动。为了这个我琢磨了一阵，记录一下。

## 一、为什么越懂越不敢动

人岁数长了反而不敢动这个事，我捋了下，感觉会有下面这几个点。

### 客观成本 - 评判尺度上的潜在成本在变大

```
不确定是最大的成本，越久成本越大
```

这个是最直观的一个感觉，刚工作那会做个新东西，我们的代价是什么呢，其实想想应该是没成本的，想做什么就做什么，反正也是什么都没有，做A与做B的代价是相同的，世界对于刚入行的年轻人也是极尽包容，事儿做不好了，也就是一句还年轻。
而工作久了再做，很可能要赌上的是职位收入以及在行业里攒的名声，因为工作经验的增长，别人对你的期望也会变得更高，每个人都在时时刻刻的被社会这把大尺子进行评判，主动或被动的关注物理世俗的评价，这时的做事成本天然就会被放大，同时社会也不会再有针对毕业生的包容。
再者当你的收入水平上升后，你自然会存在一个比较基准，这也是非常多的大厂人在当前的环境下不敢轻易动的核心原因，绝大多数的人总是想追求确定性的东西，动恰恰是不确定性的体现，年轻人的鲁莽，很多时候就是光脚不怕穿鞋的。

### 主观成本 - 人脑潜意识中的时间评判会变贵

第二个就是时间的价值在被无意识的无限拉大，随着工作年限的增长，大家总觉得时间不多了，尤其是在当前互联网这个快节奏的工作环境下，业界疯传的各种斩杀线从40 -> 35 -> 32 -> 28，一路下移，每个人都不知道明天是什么样，而自己当前已经拥有的，就会进行一个潜在的时间价值定价，我当前做这件事情与做另外一件事情，从当前的评判尺子来看，哪个收益更高？这个问题会一直在潜意识中影响着每一个人的决断，就跟我们玩游戏一样，当我尝试一条新路，会不会拉长我的通关时间？游戏尚可以无限次重试，而人生只有一次，因此时间维度的价值会在人脑中产生更多的预期外的强化。
但如果我们从整个生命的尺度来看，这个时间应当还是很多的，从25 -> 35确实是只有10年，而从35再到60依然还是有20年。

```
时间很宝贵，但另外一个尺度上，我们都还有大把的时间
```

### 经验丰富的另一面 - 抽象与拿着榔头找钉子

上面两个讲了成本相关的部分，那么我们再讲一下工作经验增长带来的坏处，也就是经验的副作用。
我们在工作中多少都会接触到经验主义，这个在工作越久的人身上体现的越为明显，经验丰富在很多时候能够帮我们规避很多的坑啊包的，但反过来答案越多，看到不对劲的东西第一反应越会是这不可能，而不是咦有点意思。创新这个事情几乎都是从咦这里不对开始的，很多的创新都起源于被忽视的噪音细节。

回想我们当年，挑战权威是常态，我们很讨厌很多条条框框的约束，对于长辈的经验很多都归结为老古董，古董在哪里，其实很多时候一个最常见的就是过度抽象，抽象本身是一个好事情，但是抽象的另一面是会过滤掉大量的细节，而创新点很可能就是隐藏在一个个不起眼的细节里的。就比如这波大模型，scaling law这个就是有点像大力出奇迹的典型代表。我们参数从几百万提升到千万提升不大，提升到1亿似乎好像也就是那么回事，但提升到十亿，它突然就涌现了。抽象是必要的，但是把抽象作为信仰并只做抽象就容易万劫不复，这也是我们很多管理者面临的问题，我们过于相信自己抓到了真理，而忽视细节实操的重要性。

同时经验这个东西还有个隐蔽的坑，经验全是从过去的具体场景里长出来的，但用着用着就当成通用法规了，见过的样本当成存在的全部，碰巧成功的事记成了因果，最后拿过去的解去拒绝新问题。就像我们做产品方案评审，最头疼听到的一句话就是，竞对就是这么做的所以我们也要这么做，似乎竞对的先验经验能够非常好的套用到我们的场景里。做技术的同学都明白，技术是没有银弹的，经验是有其使用范围的，扩大适用范围，只会在逻辑上能够做通顺的推演，但在落地上可能就是一地鸡毛，治大国如烹小鲜，同样是城市治理，杭州的治理经验套用到乌鲁木齐可能就不太行。

当然，经验的好处也是实打实的，手里其实攒下了对抗不确定性的本钱，领域范围内的快速判断同样很重要，出过的事都处理过，没出过的也知道大概往哪兜，方向感比刚工作的时候好了太多。但如何有效的利用经验，是一个很难也很重要的事情。

```
经验丰富是个褒义词，但有时候会演变为经验主义
```

### 人性的难关之一 - 关于勇气


然后才轮到勇气，而且这个勇气比较具体，就是敢不敢从0开始，重新去当个新人去学习、被纠正，作为某个领域的专家很难去适应新领域新人的这种落差。这也是我们工作中经常讲的，我们进入一个新领域要有空杯心态，但这个心态最是熬人。

回头再看最初那个问题，是不是缺了勇气。其实可能就差在这，前面三条都比勇气硬，成本账、时间账、经验账，这些是既成事实，客观事实很难变，但想要改变这些，就需要勇气，下一个决心就能变多，把问题归到勇气上，至少归到了一个自己能使上劲的地方，这算是一种对自己有用的归因。

```
无论是无知者无畏还是发自内心的勇敢，都是少年气的专属
```

### 人性的难关之二 - 我们常说的知天命是什么

三十而立、四十不惑、五十知天命，这里的知天命听着像认命的感觉，到这个岁数了知道自己的边界了就只做顺势而为的事情。但实际的知天命不是听天由命、无所作为，而是谋事在人，成事在天，努力作为但不企求结果。

如果片面的理解为躺平，反而是一种狭隘的理解，本质是我知道该做什么，以及依托于我现在的经验以及履历来做，但是是否能够成，则不受我的控制，需要做的是尽力做好自己该做的，因此这本质上也是少年气的一种体现。

```
做好自己能做的，剩下的交给天意，交给环境，无愧于内心
```

### 因果问题 - 做事与意义之间的关系

最后是最拧巴的一部分，我们现在有很多事情，做了感觉没意义，比如面对一个业务提出的新策略，很容易说这个事儿没意义，因为之前看到的历史证明了什么什么的，这甚至有段时间成了与业务battle的常用词。后来想了一下，感觉这里面要拆成两部分来看。

**评判方式带来的偏差：** 听来的真理与实践而来的懂是2个东西，实践出真知这句话大家都懂，但我们大部分的懂多半是第一种，是看别人的真知。矛盾就出在这，拿着看来的懂去评没做过的事，评出来的结论天然是不做，因为看来的东西里只算得清风险和成本，做了之后才长出来的那部分价值，站在外面是看不见的。这也是前面讲到的抽象的问题，我们看到的是别人总结以及抽象的东西，但很难了解细节，细节不清自然真理适用边界不明，这时候套出来的意义很可能是不正确的。

**先入为主的不敢做带来的没意义：** 人到了会说我怕的年纪，一般就不直说了，太掉价，换成体面的一句：没意义，然后再带点历史经验，从而证明是有理有据的没意义。但有时候意义这个事没法事先算出来，都是投入进去之后逆推出来的。少年动手的时候多半没算过意义这笔账，是做着做着才领到意义的。拿着放大镜在做之前找意义，找不到太正常了，那个阶段确实还没有东西可找。

意义这个事情同理，也是做出来的。能想出来的多半是无意义，那是站在高处往下看时自然会得出的结论，而懂得多的人平时就待在这个高度上。

```
意义是做出来的，不仅仅是想出来的
```

## 二、我们能怎么办

上面这些理完，感觉自己又懂了，也似乎是有解法了，但说起来每个人都会觉得简单，同时又有些东西是客观原因，账面改不了，时间回不去，脑子里的答案也倒不出来。那是不是就只能这样了？又想了想，倒也不是，能做的大概有这么三件事。

### 降低经验权重 - 经验做辅助而不做决策

首先就是给经验划个分工，对于外界输入的抽象要做谨慎吸收，尤其是高度抽象类的宏大叙事的总结更要搞清楚其背景以及边界，同时对于自己已经理解的要清楚的辨认清楚其边界。懂的东西管方向，选哪个战场、押哪条线、避开哪些坑，这些让它裁，确实事半功倍。但没搞清楚边界的经验，不让其进入决策。

```
不清楚细节的抽象总结，是不具备实际实践的指导能力的。
```

### 把最坏情况摆出来 - 成本未必是不可承受之痛

人在很多时候，所谓害怕怕的是不确定性，不确定性代表着手中握着的东西可能变没有。但另外一个角度来看，工作经历一年年的在涨，手里的牌比刚工作的时候厚多了，储蓄、人脉、判断力，还有踩过的坑。回顾过往很多当时看着天塌了的事，过两年回头看也就是个坑。同样一件事，不确定性还是那么大，但你消化不确定性的实力是涨的，很多时候事情确实难了，但是我们的兜底能力也强了，成功的收益也更大了。

```
把怕的东西具体写下来，最坏情况是什么，发生了怎么办，真写下来往往就会发现，大概率要么兜得住，要么压根走不到那一步。
```

### 调小决策单元 - 只看这周做不做，让自己一直在路上

创新也好，改变也罢，就像我们之前遇到的各类困难一样，克服困难的最关键的一步是分解困难。我们在做事时，有一个非常重要的技巧，就是大事化小小事化了，把要做的事情拆解掉，事情也就慢慢做成了，所谓日拱一卒也是这个道理，就像花了半年做的量化体系，每天或者每周只做一个功能，最后拼拼凑凑也成了，看起来很难的一个陌生领域的事情，其实也就是这半年的每日拱的那一卒，工作中会拆，创新也就能拆。

```
大账确实难算赢，机会成本是真的，这个不装。但小账随时算得赢，别问这件事对人生有没有意义，就问这周要不要动手做那个最小的一步。
```

### 最后收个尾

写到这里大概可以收了。岁数大了创新精神变弱，客观来看是机会成本结构发生了改变，主观角度来看是勇气的代价变大。但我们也能看到，做事的结果我们很难管，意义感也很难归我们管，我们能管的只有做，动手在路上，是做成一件事情的核心。

少年气和知天命，大概能同时住在一个工作小十年的人身上，看得比少年清，下手也不比少年慢，意义的事交给过程。
