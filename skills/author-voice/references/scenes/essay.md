# 场景：随笔

对应《少年气与知天命》。特征：千字到四千字、自我复盘、劝勉姿态、卡片存金句。

## 结构模板

1. **引子**：从一次聊天或一个触发事件切入，自曝当前状态（"第一反应已经从怎么做变成了要不要做"），三段内立起矛盾。
2. **第一章：诊断**（"一、为什么……"）：小节带类别前缀（客观成本 / 主观成本 / 经验的另一面 / 人性的难关之一 / 因果问题），前缀本身就是结构地图，读者扫目录即知每节角色。
3. **第二章：处方**（"二、我们能怎么办"）：每节一个"做法 - 效果"式标题（"降低经验权重 - 经验做辅助而不做决策"），正文给论证和场景，做法细节可以进卡片。
4. **收尾**：短，落在具体的人身上（"大概能同时住在一个工作小十年的人身上"），不喊口号。

## 语气要点

- 姿态是劝勉自己，不是指导读者：结论都说给自己（"这话首先是说给我自己听的"），承认没做到（"我自己其实也没做到""这个也还在练"）。
- 矛盾要摆出来不急着解："更有意思的是……道理都懂，但有的事情手上就是不动"。
- 行业经验直接进正文：斩杀线、评审会、与业务 battle、量化体系半年案例，随笔也用一线细节撑，不掉进纯抽象讨论。
- 金句卡片（``` 围栏）放在小节末尾，一句存档，正文不重复。

## 避坑（本场景实测翻车点）

- 对偶排比标题、"不是X而是Y"密度、段末格言、说教式收益账，这四类在本场景最容易翻车，起草后对照 style_examples.md 第 10 节逐对检查。
- 名人例子（齐白石/任正非/褚时健式）在本场景违和，删，换自己身边的事。
